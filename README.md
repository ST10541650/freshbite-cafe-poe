## Project Overview
Responsive website for FreshBite Cafe built with HTML5 and CSS3. Includes Home, Menu, Gallery, Catering and Contact pages.

## Website Structure
- `index.html` - Homepage
- `menu.html` - Menu
- `gallery.html` - Gallery
- `catering.html` - Catering services
- `contact.html` - Contact form
- `styles.css` - All styling

## Features
- Responsive navigation
- Contact form with validation
- Consistent branding
